## 🛠️ How to Compile and Run

You need a C compiler such as **GCC**.

### Compile

```bash
gcc program.c -o program
```

### Run on Windows

```bash
program.exe
```

### Run on Linux/macOS

```bash
./program
```

## 🧪 Example Program

```c
#include <stdio.h>

int main() {
```
